# raspadatom: атомдық спектр зертханасы

NIST Atomic Spectra Database деректеріне негізделген үш бөлік:

- **веб-спектрометр**: интерактивті 3D зертхана (браузерде, серверсіз);
- **ЖИ** (1D-CNN + Transformer): спектрге қарап қоспадағы түрлерді және плазма температурасын анықтайды;
- **камера бөлімі**: тор арқылы түсірілген спектр суретінен түрлерді анықтау (файл, фото, тікелей веб-камера).

## Веб-спектрометр

`dist/spectra_lab.html` файлын браузермен ашу жеткілікті: орнату да, сервер де керек емес. Дамыту нұсқасы: `web/index.html`.

| Не істейді | Қалай |
|---|---|
| 29 түр (H I … Hg I), 1–3 түрдің қоспасы, әр түрдің концентрациясы | NIST сызықтары, Больцман интенсивтілігі, pseudo-Voigt профилі, шу |
| Сәулелену және жұтылу спектрі | түс жолағы (спектроскоптағы көрініс), интенсивтілік графигі 200–900 нм, сызықтар кестесі |
| Шыңды басу → атом ауысуы | төменгі/жоғарғы деңгей, ΔE = hν, ν, A<sub>ki</sub>, күй өмірі ≈ 1/A |
| 3D атом | электронның секіруі және толқын ұзындығына пропорционал фотон; қозу, шығару, жұтылу, шашырау |
| Гротриан диаграммасы | деңгейлер (s, p, d, f бағандары), барлық ауысулар, таңдалғаны қалың көрсеткімен |
| 3D призмалық спектрометр | көз → саңылау → призма → экран; Снелл заңы, әр λ үшін өз n(λ) |
| ЖИ талдауы | модель браузердің ішінде (таза JS) жұмыс істейді: түрлердің ықтималдығы және T |
| «Белгісіз қоспа» | жасырын қоспаның спектрі; гипотеза таңдап, NIST сызықтарын салыстырыңыз немесе ЖИ-ден сұраңыз |

Қайта жинау:

```bash
python tools/export_web.py   # data/nist_lines.csv + checkpoints/spectral_net.pt -> web/data/*.js
python tools/build_web.py    # web/ -> dist/spectra_lab.html (бір файл)
```

## Камера және сурет арқылы спектр тану

«Камера» бөлімі дифракциялық тор арқылы түсірілген спектр суретін (файл, телефон фотосы, тікелей веб-камера) талдайды. Қолмен нақты жұмыс ретімен:

1. **Қондырғы:** камера объективінің алдына тор (CD/DVD-дан немесе тор пленкасынан), жарық көзіне қараңыз. Қондырғыны қозғалтпаңыз.
2. **Калибровка:** флуоресцентті (CFL) шамның спектрін түсіріңіз де, «Автокалибровка» басыңыз. Hg 435.8, Tb 487.7, Tb/Hg 544.5, Hg 577/579, Eu 611.6 нм шыңдары табылып, λ = a·пиксель + b есептеледі. Қолмен калибровка да бар (екі сызық, мыс. 405/532/650 нм лазерлер).
3. **Өлшеу:** белгісіз көзді түсіріңіз. Модель көрінетін аймақтағы (380–780 нм) спектрге қарап түрлерді анықтайды, ал графиктегі штрихтар болжам сызықтарының спектрде бар-жоғын көрсетеді.

Кескін → спектр (`web/js/camera.js`):

- жолақты табу: хроматикалық карта бойынша PCA (спектр түсті, шам жарқылы ақ), жарқыл дақ кесіліп тасталады, бұрыш пен қисықтық ескеріледі;
- профиль: sRGB → сызықтық жарық, жолақ бойымен орташа, фон алынады;
- калибровка, модель торына (380–780 нм, 1024 нүкте) келтіру;
- тексеру: болжанған түрдің негізгі сызықтары спектрде бар ма, түсіндірілмеген шыңдар (мыс. Eu³⁺/Tb³⁺ фосфор) қандай.

Модель (`spectra_ai/synth_cam.py`, `python -m spectra_ai.train --domain camera`): 28 түр; оқыту спектрлеріне камераның бұрмалаулары қосылған: ажыратымдылық 1.5–10 нм, калибровка қателігі, сезімталдық қисығы (көк/IR шектері), қанығу, фон (қыздыру шамы, LED, фосфор «төбелері»), бөгде сызықтар (фосфор), NIST пен нақты шам арасындағы интенсивтілік айырмасы, атомдық түрі жоқ спектрлер. Белгі тек байқалатын түрге қойылады (өз шыңы толық масштабтың ≥5% және шудан ≥3σ жоғары).

| Көрсеткіш | Мән |
|---|---|
| Камера моделі, синтетикалық валидация (3000 спектр): F1 / precision / recall | 0.823 / 0.871 / 0.779 |
| 1-қадамның лаборатория моделі сол камера спектрлерінде | F1 0.176 (сондықтан бөлек модель керек) |
| F1: бір / екі / үш түр | 0.91 / 0.82 / 0.74 |
| F1: калибровка қателігі < 2 / 2–5 / > 5 нм | 0.86 / 0.84 / 0.66 |
| Толық құбыр, 400 виртуал фото: жолақ табылмау | 0 / 400 |
| Толық құбыр: CFL автокалибровкасы | 53 / 53, RMS 0.29 нм |
| Толық құбыр F1 (үздіксіз спектр қақпасымен): бір / екі / үш түр, барлығы | 0.85 / 0.86 / 0.72, жалпы 0.80 |
| Үздіксіз спектр (қыздыру шамы, LED): жалған түр | 0 / 35 (қақпамен; қақпасыз 14 / 35) |
| «Расталған» түрлер (сызық сәйкестігі): precision / recall | 0.94 / 0.60 |

Ең төмен recall жеке сызығы аз түрлерде: Na I 0.49, O I 0.61, H I 0.65, Hg I 0.66. Жалғыз сызықты көздегі бөгде сызық пен калибровка қателігі оны шын сызықтан ажыратуға мүмкіндік бермейді. Сондықтан нәтижеде екі қорғаныс бар: тар шыңдар жоқ спектрде («қыздыру шамы», LED) түр айтылмайды, ал әр болжам сызық сәйкестігімен «расталды/расталмады» деп белгіленеді.

**Мұны оқығанда есте ұстаңыз:** виртуал фотолар мен оқыту генераторы ортақ болжамдарды бөліседі, ал нақты веб-камера бұлардан өзгеше болуы мүмкін. Сондықтан бұл сандар құбырдың дұрыс жұмыс істейтінін растайды, бірақ нақты камерадағы дәлдікті бермейді. Нақты суретпен сынап көріп, графиктегі штрихтарды (болжам сызықтары) өлшенген шыңдармен салыстырыңыз.


Виртуал камера (`web/js/camsim.js`) тор бұрышын, қисықтықты, виньетканы, нөлінші ретті жарқылды, ауа жарығын, шуды, RGB сезімталдығын, IR-фильтрді, қанығуды модельдейді. Бұл камерасыз сынау мен мысал көрсету үшін, нақты фото емес.

## Деректер

`data/nist_lines.csv`: 5170 сызық, 29 түр. Әр жолда ауадағы (`wl_nm`) және вакуумдағы (`wl_vac_nm`) толқын ұзындығы, `rel` (NIST салыстырмалы интенсивтілігі), `aki`, төменгі/жоғарғы деңгей энергиясы (`ei_ev`, `ek_ev`, эВ), статистикалық салмақтар және деңгей белгілері бар.

Сүзгілер (`spectra_ai/nist.py`):

- `Ei < Ek < E_иондану`: автоиондану деңгейлерінен шығатын жолдар алынбайды. NIST «Cu I» сұрауының 400 жолының 298-і осындай болатын, олар қалыпты плазмада көрінбейді;
- `|Ek − Ei − hc/λ_vac| < 0.01 эВ`: энергия сақталуы тексеріледі;
- толқын ұзындығы стандартты ауаға келтіріледі (Peck & Reeder 1972): Na D₂ = 588.995 нм, Hα = 656.279 нм, Hg = 253.652 нм.

## Модель

`spectra_ai/model.py`: екі арна (I және √I), екі конволюция блогы, позиция кодтауы бар 2 қабатты Transformer, екі шығыс: түрлер (көп белгілі, sigmoid) және температура. 81 598 параметр.

Оқыту деректері NIST сызықтарынан әр эпохада жаңадан жасалады (`spectra_ai/synth.py`): 1–3 түр, T = 4000–15000 K, ажыратымдылық 0.6–3 нм, шу, базалық сызық, калибровка ығысуы.

| Көрсеткіш (синтетикалық валидация, 2000 спектр) | Мән |
|---|---|
| F1 / precision / recall | 0.976 / 0.991 / 0.961 |
| Қоспа толық дұрыс | 91% |
| Температура қателігі (MAE) | 591 K |
| JS құбыры (JS генератор + JS модель, 400 спектр) | F1 = 0.976 |

JS порты PyTorch-пен 10⁻⁶ дәлдікте сәйкес келеді, JS генераторы Python генераторымен 10⁻⁹ дәлдікте (`tests/test_web.py`).

## Шектеулер

- Модель тек синтетикалық спектрлерде оқытылған; нақты спектрометр деректерімен тексерілмеген.
- Интенсивтілік NIST `Rel.` шамасынан жасалады, ол T = 10 000 K-ге байланған шартты шама. Жұтылу сызықтарының күші де осыдан бағаланады (`S ∝ Rel·λ³·e^{Ek/kT_ref}·e^{−Ei/kT}`), сондықтан ол сапалық сипатта.
- Жұтылу режимінде ЖИ өшірулі: модель сәулелену спектрінде оқытылған.
- 3D атомда деңгей энергиялары NIST-тен алынған, ал орбита радиусы схемалық (`r ∝ n_eff^0.85`). Сутегі үшін Бор моделі. Кванттық секіру нақты траектория емес.
- Призмада дисперсия көрнекілік үшін нақты флинттен ~3 есе үлкейтілген; УК әйнекте жұтылады, сондықтан көрсетілмейді.
- Камера моделі мен камера құбыры нақты камерамен тексерілмеген (жоғарыдағы ескертуді қараңыз). Фосфор (Eu/Tb) және молекулалық жолақтар класс емес: CFL үшін тек Hg I айтылады.
- claude.ai-дағы жарияланған бетте тікелей камера өшірулі (қорғалған орта); суретті жүктеу және виртуал камера жұмыс істейді. Тікелей камера үшін `dist/spectra_lab.html` файлын жергілікті ашыңыз.
