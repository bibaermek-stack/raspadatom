# raspadatom: атомдық спектр зертханасы

NIST Atomic Spectra Database деректеріне негізделген үш бөлік:

- **веб-спектрометр**: интерактивті 3D зертхана (браузерде, серверсіз);
- **ЖИ** (1D-CNN + Transformer): спектрге қарап қоспадағы түрлерді және плазма температурасын анықтайды;
- **камера бөлімі**: тор арқылы түсірілген спектр суретінен түрлерді анықтау (файл, фото, тікелей веб-камера).

## Веб-спектрометр

`dist/spectra_lab.html` файлын браузермен ашу жеткілікті: орнату да, сервер де керек емес. Дамыту нұсқасы: `web/index.html`.

| Не істейді | Қалай |
|---|---|
| 29 түр (H I … Hg I), 1–3 түрдің қоспасы, әр түрдің концентрациясы | NIST сызықтары, Больцман интенсивтілігі, pseudo-Voigt профилі, шу |
| Сәулелену және жұтылу спектрі | түс жолағы (спектроскоптағы көрініс), интенсивтілік графигі 200–900 нм, сызықтар кестесі |
| Шыңды басу → атом ауысуы | төменгі/жоғарғы деңгей, ΔE = hν, ν, A<sub>ki</sub>, күй өмірі ≈ 1/A |
| 3D атом | электронның секіруі және толқын ұзындығына пропорционал фотон; қозу, шығару, жұтылу, шашырау |
| Гротриан диаграммасы | деңгейлер (s, p, d, f бағандары), барлық ауысулар, таңдалғаны қалың көрсеткімен |
| 3D призмалық спектрометр | көз → саңылау → призма → экран; Снелл заңы, әр λ үшін өз n(λ) |
| ЖИ талдауы | модель браузердің ішінде (таза JS) жұмыс істейді: түрлердің ықтималдығы және T |
| «Белгісіз қоспа» | жасырын қоспаның спектрі; гипотеза таңдап, NIST сызықтарын салыстырыңыз немесе ЖИ-ден сұраңыз |

Қайта жинау:

```bash
python tools/export_web.py   # data/nist_lines.csv + checkpoints/spectral_net.pt -> web/data/*.js
python tools/build_web.py    # web/ -> dist/spectra_lab.html (бір файл)
```

### Vercel-ге орналастыру

Сайт статикалық: `vercel.json` Vercel-ге `dist/` папкасын дайын шығыс ретінде береді (`/` → `dist/spectra_lab.html`), құрастыру мен орнату қадамдары жоқ. Бұл міндетті: репода `requirements.txt` бар, сондықтан Vercel жобаны Python қолданбасы деп қабылдап, `PYTHON_ENTRYPOINT_NOT_FOUND` қатесімен құлайтын (`framework: null` оны өшіреді). Жаңарту: `python tools/build_web.py`, `dist/` коммиттеп push жасаңыз, Vercel өзі жариялайды. HTTPS болғандықтан тікелей веб-камера да жұмыс істейді. Бір репоны бірнеше рет импорттасаңыз, артық жобалар пайда болады: біреуін қалдырып, қалғанын Vercel dashboard-тан жойыңыз.

### Өлшеулер, CSV және салыстыру

- Зертханада немесе калибрленген камерада **Өлшеулерге ашу** түймесін басыңыз. Өлшеуге атау беріп, браузер тарихына сақтауға немесе CSV жүктеуге болады. Камера спектрін тасымалдау үшін CFL не екі нүкте бойынша калибровка қажет.
- **Өлшеулер** қойындысында басқа спектрометрдің CSV файлын импорттаңыз немесе тарихтан өлшеуді ашыңыз. Салыстыру үшін екінші сақталған өлшеуді таңдаңыз. Екінші спектр үзік сызықпен салынады. Қисықтар пішіні мен шыңдарының орнын салыстыру үшін әр спектр өз қарқындылығының ең үлкен абсолют мәніне бөлінеді. CSV-де бастапқы мәндер сақталады.
- CSV бағандары — `wavelength_nm,intensity,peak`. Толқын ұзындығын нанометрмен беріңіз. Үшінші баған міндетті емес. Экспортта `0` үлгі нүктесін, `1` шыңмен сәйкес келетін үлгі нүктесін, ал `peak_only` тордан бөлек шыңның орнын және биіктігін білдіреді. Үтір, нүктелі үтір немесе табуляция бөлгіштері бар екі бағанды файлды да ашуға болады. Үлгі нүктелеріндегі толқын ұзындығы қайталанбауы керек. Шек — 8 МБ және 50 000 нүкте.
- Импортталған спектрдің құрамын бағалау 380–780 нм аймағындағы камера моделін қолданады. Аралық жеткіліксіз, өлшем торында үлкен үзілістер бар немесе спектр сызықтары болжамды қолдамаса, интерфейс құрамды белгісіз деп көрсетіп, күмәнді түрлерді бөлек шығарады.

## Камера және сурет арқылы спектр тану

«Камера» бөлімі дифракциялық тор арқылы түсірілген спектр суретін (файл, телефон фотосы, тікелей веб-камера) талдайды. Қолмен нақты жұмыс ретімен:

1. **Қондырғы:** камера объективінің алдына тор (CD/DVD-дан немесе тор пленкасынан), жарық көзіне қараңыз. Қондырғыны қозғалтпаңыз.
2. **Калибровка:** флуоресцентті (CFL) шамның спектрін түсіріңіз де, «Автокалибровка» басыңыз. Hg 435.8, Tb 487.7, Tb/Hg 544.5, Hg 577/579, Eu 593/611.6/650/690/700 нм шыңдары табылып, λ = a·пиксель + b (5 және одан көп сызықта квадраттық мүше де: объектив дисперсияны қисайтады) есептеледі. Сәйкестік шыңның **түсімен** тексеріледі: нақты фотода қаныққан жасыл сызық бір орынға қателесіп Hg 435.8 болып кетпеуі үшін. CFL сызықтары табылмаса, түс бойынша шамамен калибровка (±15–20 нм) ұсынылады, ол бағдар ретінде ғана. Қолмен калибровка да бар (екі сызық, мыс. 405/532/650 нм лазерлер).
3. **Өлшеу:** белгісіз көзді түсіріңіз. Модель көрінетін аймақтағы (380–780 нм) спектрге қарап түрлерді анықтайды, ал графиктегі штрихтар болжам сызықтарының спектрде бар-жоғын көрсетеді.

**Калибровка сапасы** сәйкестендірілген эталон сызықтарын, әр сызықтың ауытқуын, RMS және ең үлкен ауытқуды көрсетеді. Екі нүктелік калибровканы бөлек эталон сызығымен тексеріңіз. **Калибровка профильдері** кадр өлшемін, жолақ геометриясын және калибровканы браузерде сақтайды. Профильді камера, тор және кадрлау сол күйінде болғанда қайта қолданыңыз. Өлшеу тарихы мен профильдер осы браузерде сақталады.

Телефонда **Үлкейту**, **Толық аралық** және шыңдар арасында өту түймелерін қолданыңыз. Жолақты қолмен белгілеу үшін **Жолақты сызу** түймесін басып, суреттегі спектр бойымен саусақпен сызық сүйреңіз.

Кескін → спектр (`web/js/camera.js`):

- жолақты табу: PCA хроматикалық картадан бастапқы осьті анықтайды. Алгоритм ақ жарқылдың көршілес түсті сызықтарға әсерін азайтып, жеткілікті дерек болса қисық жолақты қадағалайды. Автоматты табу сәтсіз болса, суретте жолақ бойымен сызық сүйреп ROI-ды қолмен беруге болады;
- профиль: sRGB → сызықтық жарық, жолақ бойымен орташа, фон алынады;
- калибровка, модель торына (380–780 нм, 1024 нүкте) келтіру;
- тексеру: болжанған түрдің негізгі сызықтары спектрде бар ма, түсіндірілмеген шыңдар (мыс. Eu³⁺/Tb³⁺ фосфор) қандай.

Модель (`spectra_ai/synth_cam.py`, `python -m spectra_ai.train --domain camera`): 28 атомдық түр және «CFL» көз класы (люминофорлы флуоресцентті шам: Hg + Tb³⁺/Eu³⁺ сызықтары). Оқыту спектрлеріне камераның бұрмалаулары қосылған: ажыратымдылық 1.5–10 нм, ал 20% жағдайда 8–28 нм (нашар фокус, қаныққан кең сызықтар), калибровка қателігі мен сызықтық емес дисперсия, сезімталдық қисығы (көк/IR шектері), қанығу және блуминг (жарықтың айналаға таралуы), фон (қыздыру шамы, LED, фосфор «төбелері»), бөгде сызықтар, NIST пен нақты шам арасындағы интенсивтілік айырмасы, атомдық түрі жоқ спектрлер. Белгі тек байқалатын түрге қойылады (өз шыңы толық масштабтың ≥5% және шудан ≥3σ жоғары).

**v3 генераторы нақты спираль-CFL фотосын көргеннен кейін жасалды** (кең қаныққан сызықтар, фосфор басымдығы, сызықтық емес дисперсия). Сондықтан сол фотодағы нәтиже тәуелсіз тест емес. Модель v2 чекпойнтынан 8 эпоха бойы (≈6 минут CPU-да) жаңа генератормен қайта оқытылды (`--init`).

Салыстыру: v2 моделімен сол виртуал фотолар (400, бір тұқым). Жалпы F1 (қақпамен) 0.80 → 0.82; «расталған» түрлер precision/recall 0.94/0.60 → 0.96/0.66; бір / екі / үш түр F1 0.85/0.86/0.72 → 0.88/0.84/0.71. Тар сызықты виртуал фотоларда жақсарудың көбі CFL көзінен (оның белгісі енді «CFL» + Hg I, сондықтан тікелей салыстыру емес), ал бір/екі/үш түрдегі айырма шу деңгейінде. Негізгі пайда: кең, қаныққан сызықтар мен CFL (жоғарыдағы синтетикалық тест: F1 0.68 → 0.76).

Ең төмен recall (v3, синтетикалық тест) жеке сызығы аз түрлерде: Na I 0.34, O I 0.44, Ar I 0.52, Mn I 0.54, Al I 0.55, H I 0.56. Белгінің көрінулік шегі мұның себебі емес (өлшенді): оң белгілердің тек 5.5 %-ында түрдің өз шыңы толық масштабтың 10 %-ынан төмен, ал Na I-дың өз шыңының медианасы 60 %, соған қарамастан recall 0.34. Recall көрінулікке қарай өседі (өз шыңы < 10 % / 10–20 % / 20–50 % / ≥ 50 %: 0.35 / 0.47 / 0.58 / 0.83), бірақ ең көрінетін оң белгілерде де 0.83-тен аспайды. Жалғыз сызықты көздегі бөгде сызық пен калибровка қателігі (±5 нм) оны шын сызықтан ажыратуға мүмкіндік бермейді (Na D 589 нм Eu³⁺ 593 нм және Hg 577/579 нм сызықтарына жақын). Жалған оң шешімдердің тек 7 %-ы «спектрде бар, бірақ шектен төмен» түрлерден, қалғаны — шын шатасулар. Сондықтан нәтижеде екі қорғаныс бар: тар шыңдар жоқ спектрде («қыздыру шамы», LED) түр айтылмайды, ал әр болжам сызық сәйкестігімен «расталды/расталмады» деп белгіленеді.

**Ұзағырақ оқыту көмектеспейді (тексерілді).** Камера моделін 24 эпоха қосымша оқыту (`python -m spectra_ai.train --domain camera --epochs 24 --lr 5e-4 --seed 2 --init checkpoints/camera_net.pt`; train loss −17 %) синтетикалық тестте F1-ді 0.761 → 0.779 өсіреді (жұптасқан ΔF1 = +0.018, ДИ [0.013; 0.025]), бірақ 1 500 виртуал фотодағы толық құбырда айырма жоқ (қақпамен F1 0.835 vs 0.834, расталған 0.776 vs 0.777), әлсіз түрлер әлсіз күйінде қалады (Na I 0.34 → 0.35, O I 0.44 → 0.51, H I 0.56 → 0.60), ал таза бос спектрдегі жалған оң өзгермейді (12.6 % vs 12.5 %). Сондықтан чекпойнт ауыстырылған жоқ. Бұл шектеу оқыту ұзақтығында емес екенін көрсетеді; ықтимал себеп — калибровка қателігімен бірге бір сызықты түрлердің ажыратылмауы.

**Мұны оқығанда есте ұстаңыз:** виртуал фотолар мен оқыту генераторы ортақ болжамдарды бөліседі, ал нақты веб-камера бұлардан өзгеше болуы мүмкін. Сондықтан бұл сандар құбырдың дұрыс жұмыс істейтінін растайды, бірақ нақты камерадағы дәлдікті бермейді. Нақты суретпен сынап көріп, графиктегі штрихтарды (болжам сызықтары) өлшенген шыңдармен салыстырыңыз.


Виртуал камера (`web/js/camsim.js`) тор бұрышын, қисықтықты, виньетканы, нөлінші ретті жарқылды, ауа жарығын, шуды, RGB сезімталдығын, IR-фильтрді, қанығуды модельдейді. Бұл камерасыз сынау мен мысал көрсету үшін, нақты фото емес.

## Нақты фотолармен тексеру

Тек **екі** нақты сурет қолжетімді болды (дереккөздері мен лицензиялары `docs/real_photos.md` ішінде; суреттер репозиторийде жоқ). Бұл статистика емес, диагностика. Құрал: `python tools/eval_real.py photo.jpg [--roi ...]`.

| Сурет, ROI | Калибровка | v2 жауабы | v3: үздік 3 | v3 болжамы → расталғаны |
|---|---|---|---|---|
| Спираль CFL, ROI қолмен | CFL, 5 сызық, RMS 1.12 нм, квадраттық | H I 43%, Ni I 18%, Na I 16%: болжам жоқ | Ba I 76%, Hg I 52%, H I 23% | Ba I, Hg I → Hg I |
| CD кемпірқосағы, ROI автомат | CFL, 3 сызық, RMS 0.79 нм: сенімсіз | O I 48%, Li I 28%: болжам жоқ | Li I 56%, O I 34%, Na I 11% | Li I → — |
| CD кемпірқосағы, ROI қолмен | CFL, 3 сызық, RMS 0.19 нм: сенімсіз | Hg I 27%, H I 10%: болжам жоқ | Hg I 84%, CFL 43%, O I 9% | Hg I → Hg I |

Оқылатыны:

- **Спираль CFL:** v2 ештеңе айта алмады (барлығы <50%). v3 **Hg I 52%** айтты: дұрыс (флуоресцентті шамда сынап бар), сызық сәйкестігімен расталды. Сонымен қатар **Ba I 76%** жалған оң, бірақ ол расталмады және интерфейсте «расталмады» деп белгіленеді. Арнайы «CFL» класы бұл фотода танылмады (үздік 5-те жоқ). Бұл фото v3 генераторын жобалауға әсер еткен, сондықтан тәуелсіз тест емес.
- **CD кемпірқосағы:** автоматты ROI қате аймақты алады («бір сызық» қайтарымы), нәтиже мағынасыз (Li I 56%, расталмады). Кемпірқосақты көлденең кесетін қолмен ROI-мен: Hg I 84% (расталды), CFL 43%. Флуоресцентті түтікке сәйкес, бірақ калибровка тек үш сызықпен жасалған және кемпірқосақ шешілмеген (≈30–40 нм кең «сызықтар»): бұл нәтижеге сенім төмен.
- ROI дұрыс берілгенде екі суретте де Hg I табылып расталды (v2: ештеңе), бірақ жалған оң қалды (Ba I; қате ROI-да Li I де шықты): оны тек сызық сәйкестігімен растау қорғайды. n = 2 — жақсару белгісі, дәлел емес.
- Модель нақты фотоларда **оқытылған жоқ**: екі сурет оқытуға да, дұрыс валидацияға да жеткіліксіз. v3 — нақты фотодан көрілген бұрмалауларды синтетикалық оқытуға қосу (domain randomization). Нақты дәлдікті бағалау үшін кемінде 30–50 белгіленген сурет (жарық көзі белгілі, түрлі камера мен тор) керек.

## Деректер

`data/nist_lines.csv`: 5170 сызық, 29 түр. Әр жолда ауадағы (`wl_nm`) және вакуумдағы (`wl_vac_nm`) толқын ұзындығы, `rel` (NIST салыстырмалы интенсивтілігі), `aki`, төменгі/жоғарғы деңгей энергиясы (`ei_ev`, `ek_ev`, эВ), статистикалық салмақтар және деңгей белгілері бар.

Сүзгілер (`spectra_ai/nist.py`):

- `Ei < Ek < E_иондану`: автоиондану деңгейлерінен шығатын жолдар алынбайды. NIST «Cu I» сұрауының 400 жолының 298-і осындай болатын, олар қалыпты плазмада көрінбейді;
- `|Ek − Ei − hc/λ_vac| < 0.01 эВ`: энергия сақталуы тексеріледі;
- толқын ұзындығы стандартты ауаға келтіріледі (Peck & Reeder 1972): Na D₂ = 588.995 нм, Hα = 656.279 нм, Hg = 253.652 нм.

## Модель

`spectra_ai/model.py`: екі арна (I және √I), екі конволюция блогы, позиция кодтауы бар 2 қабатты Transformer, екі шығыс: түрлер (көп белгілі, sigmoid) және температура. 81 790 оқытылатын параметр (BatchNorm конволюцияға біріктірілген соң браузерде 81 598).

Оқыту деректері NIST сызықтарынан әр эпохада жаңадан жасалады (`spectra_ai/synth.py`): **1–8 түр** (`--max-species`; нақты LIBS үлгілері көп элементті), T = 4000–15000 K, ажыратымдылық 0.6–3 нм, шу, базалық сызық, калибровка ығысуы.

Лаборатория моделінің үш нұсқасы:

- **v1**: бастапқы модель, 1–3 түрлі қоспа (чекпойнтта эпоха саны сақталмаған; жылдам бастаудағы пәрмен 30 эпоха).
- **v2**: v1-ден 6 эпоха қосымша (әр эпохада 12 000 спектр, 1–3 түр).
- **v3 (қазір)**: v2-ден 20 эпоха қосымша, әр эпохада 20 000 жаңа спектр, **1–8 түр**: `python -m spectra_ai.train --epochs 20 --max-species 8 --seed 2 --init checkpoints/spectral_net.pt`.

Тест: оқыту (seed 1/2) мен валидацияға (seed 999) кірмеген 4 000 жаңа синтетикалық спектр (seed 20261116, әр спектрде 1–3 түр). Бұл хаттаманың скрипті: `python -m spectra_ai.eval_lab` (сенім аралықтары спектрлерді қайта таңдау арқылы, bootstrap).

## Нақты LIBS-та тексеру (SuperLIBS)

Жоғарыдағы сандар — синтетикада, яғни оқыту генераторымен бір таралымда. Лаб-модельді **нақты** спектрде өлшеу үшін `spectra_ai/eval_libs_species.py` бар: [SuperLIBS 10K](https://zenodo.org/records/10287455) (2 503 нақты LIBS спектрі, 8 оксидтің құрамы белгілі; Жер атмосферасы, 2.4 мДж). Модель онда **оқытылмаған**, сондықтан барлық спектр — тест.

```bash
python -m spectra_ai.eval_libs_species --data data/zenodo.10K_EARTH.2.4mJ.csv --checkpoint checkpoints/spectral_net.pt --errors-csv libs-errors.csv
```

JSON есебінде әр элемент үшін ≥ 1 және ≥ 5 wt % топтарындағы анықталған және өткізіп алынған спектрлердің саны, сондай-ақ белгілі жоқ түрлер бойынша жалған дабыл саны беріледі. CSV кестесі әр модель мен концентрация шегі бойынша өткізіп алу жиілігімен, ал жалған дабыл жолдары жиілікпен кему ретімен сұрыпталады. Топта спектр болмаса, жиілік ұяшығы бос қалады. Әдепкіде модель ықтималдығы 0.5-тен жоғары болса, элемент анықталды деп есептеледі. Шекті `--threshold` арқылы беруге болады.

Белгілеу туралы: пеллеттер көп элементті (орташа 6.4 оксид ≥ 1 wt %), ал негізгі элементтердің резонанс сызықтары 0.1 wt %-да да көрінеді (Ca II 393 нм барлық спектрде). Сондықтан «≥ 1 wt % = бар, қалғаны = жоқ» деген белгі precision өлшеуге жарамайды, және F1 берілмейді. Орнына екі таза өлшем алынды: (1) 8 негізгі элементтің **анықталу жиілігі** (оксид ≥ 1 wt % болғанда), (2) пеллетте **болуы мүмкін емес** түрлер (He, Ne, Kr, Xe, Hg, Cd) бойынша **жалған дабыл** жиілігі. Ar, N, O, H, C ауадан көрінуі мүмкін, сондықтан «жоқ» тізімінде емес.

Өңдеу: спектр модель торына (200–900 нм, 2048 нүкте) орташаланып қайта бөлінеді, екі спектрометр саңылауы (351–370, 479–508 нм) = 0, Гаусс FWHM 1.3 нм (оқыту ауқымының ортасы), max = 1. Тегістеуді нақты белгілерге емес, синтетикалық in-silico тексеру негізінде таңдадым: NIST сызықтарын SuperLIBS-тың өз арна торына (саңылауларымен) салғанда, FWHM 0.15 нм сызықтарда тегістеусіз v2 нашар жұмыс істейді (k = 1: F1 0.90 → 0.99 тегістеумен). In-silico тексеруден бұрын v2-ні нақты деректе тегістеусіз де, тегістеумен де өлшеп көрдім: нәтиже ұқсас (микро-recall ≈ 0.51 vs 0.50), сондықтан бұл таңдау қорытындыға әсер етпейді. v3 тек осы негізгі өңдеумен нақты деректе бір рет өлшенген, оған қарап баптау жасалмаған; тек k ≤ 8 таңдауы пеллеттердің көп элементті екенін (жоғарыдағы статистика) көргеннен кейін жасалған.

| Элемент (оксид ≥ 1 wt %) | Спектр саны | v2 (1–3 түр) | v3 (1–8 түр) |
|---|---|---|---|
| Si | 2 501 | 0.978 | **1.000** |
| Ti | 1 335 | 0.000 | 0.000 |
| Al | 2 454 | 0.000 | 0.232 |
| Fe | 2 347 | 0.001 | **0.869** |
| Mg | 1 842 | 0.876 | **0.999** |
| Ca | 1 938 | 0.935 | **0.997** |
| Na | 2 192 | 1.000 | 1.000 |
| K | 1 434 | 0.000 | 0.015 |
| **Микро-recall (≥ 1 wt %)** | | 0.503 | **0.692** |
| Hg I жалған дабыл (пеллетте жоқ түр) | 2 503 | 48.3 % | 28.6 % |
| He, Ne, Kr, Xe, Cd жалған дабылы | 2 503 | 0 % | ≤ 0.04 % |

Оқылатыны:

- **Көп түрлі қоспа — нақты проблема.** v2 8 элементтің жартысын (Fe, Al, K, Ti) мүлде таппайды; v3 Fe, Mg, Ca, Si-ды дерлік толық табады. Бұл синтетикадағы құлдырауға (жоғарыдағы стресс-тест) сәйкес.
- **Нақты деректе калибровка нашар.** Hg I (пеллетте болуы мүмкін емес) v3-те 50 %-дан жоғары ықтималдықпен 28.6 % спектрде айтылады, шын жиілік 0. Синтетикадағы ECE 0.004 нақты деректегі сенімділікке кепіл емес.
- **K, Ti және Al табылмауының себептері (өлшенген бөлігі):** K I-дың NIST `Rel` мәндері жалпақ (766 нм: 25, 694 нм: 20, 404 нм: 18, 580 нм: 17), сондықтан модель K I-ды «бірнеше шамалас күшті сызық» деп үйренген. Нақты K-ға бай пеллеттерде (K₂O ≥ 3 wt %) 766/770 нм резонанс жұбы 694/691 нм сызықтарынан 50–160 есе, 580 нм сызығынан ≈ 240–320 есе (583 нм көрінбейді), 404 нм жұбынан 4–8 есе күшті. Бұл жұптың өзі кеңейген: 30 ең бай пеллетте 766.49 нм сызығының FWHM-і ≈ 1.2 нм (арна қадамы 0.03–0.05 нм). Ti үшін: NIST бойынша ең күшті 10 Ti I сызығының 6-уы (498–507 нм) спектрометр саңылауына (479–508 нм) түседі, ең күшті 521.04 нм сызығы нақты спектрде әлсіз (0.1·10⁻³, ал Ca II ≈ 10⁻²), ал Ti II (334.9 нм: 1.6·10⁻³) модельде жоқ. Al I 394/396 нм жұбының табылмауы үшін ықтимал себеп — Ca II 393/397 нм кең сызықтарымен араласу, бірақ бұл тексерілмеген болжам.
- K-ның сәтсіздігі — NIST `Rel` интенсивтілігінің нақты плазмадағы қатынастардан алшақтығының салдары (шектеулер бөлімінде айтылған). Келесі қадам — сызық күшін LTE-ден (`g_k·A_ki·exp(−E_k/kT)`, деректе `aki`, `gk` бар) есептеу және Ti II сияқты иондық сызықтарды қосу. Ол синтетикалық генераторды, JS физикасын және парити тесттерін бірге өзгертуді талап етеді, сондықтан бұл өзгеріске енгізілмеді.
- Модель нақты спектрдегі басқа түрлерді де айтады (Ar I 27 %, C I 40 %, Li I 42 %, O I 45 % спектрде): Ar, C, O ауа мен ылғалдан, Li — із ретінде мүмкін, бірақ бұл түрлер үшін нақты белгі жоқ.
- Бұл бір дерек (бір аспап, бір атмосфера, бір энергия) әрі тау жыныстарын құрайтын 8 элемент ғана. Жалпы нақты дәлдік деп оқуға болмайды.

Веб-зертханада модель өз генераторының спектрін талдайды (оқыту таралымында), сондықтан бұл нәтижелер веб-демонстрацияға әсер етпейді: олар модельді нақты LIBS-қа қолдануға қатысты.

## Шектеулер

- Веб-зертхана мен камера модельдері синтетикалық спектрлерде оқытылған. Синтетикалық F1 нақты дәлдік емес: нақты LIBS-та лаб. модель (v3) ≥ 1 wt % элементтердің тек 69 %-ын табады, пеллетте жоқ Hg I-ды 29 % спектрде айтады («Нақты LIBS-та тексеру» бөлімі). Камера моделі үшін нақты дәлдік сандары жоқ.
- Лаб. генератор мен камера генераторының белгі анықтамасы әртүрлі: лаб.-та таңдалған барлық түр белгі (`spectra_ai/synth.py`), камерада тек көрінетіні, өз шыңы ≥ 5 % (`spectra_ai/synth_cam.py`). Сондықтан лаб. F1 мен камера F1 салыстырылмайды.
- Интенсивтілік NIST `Rel.` шамасынан жасалады, ол T = 10 000 K-ге байланған шартты шама. Жұтылу сызықтарының күші де осыдан бағаланады (`S ∝ Rel·λ³·e^{Ek/kT_ref}·e^{−Ei/kT}`), сондықтан ол сапалық сипатта. Нақты LIBS-та K мен Ti табылмауының өлшенген себебі де осы (жоғарыдағы бөлім).
- Жұтылу режимінде ЖИ өшірулі: модель сәулелену спектрінде оқытылған.
- 3D атомда деңгей энергиялары NIST-тен алынған, ал орбита радиусы схемалық (`r ∝ n_eff^0.85`). Сутегі үшін Бор моделі. Кванттық секіру нақты траектория емес.
- Призмада дисперсия көрнекілік үшін нақты флинттен ~3 есе үлкейтілген; УК әйнекте жұтылады, сондықтан көрсетілмейді.
- Камера моделі мен камера құбыры нақты камерамен жүйелі түрде тексерілмеген: тек екі нақты сурет бар (жоғарыдағы бөлім). Фосфор (Eu/Tb) тек «CFL» көз класы ретінде бар; молекулалық жолақтар (OH, N₂, CN) жоқ.
- Нақты фотода жолақты автоматты табу сәтсіз болуы мүмкін (доға, кемпірқосақ): ROI-ды сүйреп беріңіз.
- claude.ai-дағы жарияланған бетте тікелей камера өшірулі (қорғалған орта); суретті жүктеу және виртуал камера жұмыс істейді. Тікелей камера үшін `dist/spectra_lab.html` файлын жергілікті ашыңыз.

## Жол картасы: ғылыми зертханалық дәлдікке не жетпейді

Төмендегі алты бағыт қажет, бірақ көбі әлі **жасалған жоқ**. Күйі шынайы көрсетілген.

| # | Бағыт | Күйі | Қазір не бар | Не жоқ / келесі қадам |
|---|---|---|---|---|
| 1 | Сандық талдау (концентрация, Saha–Boltzmann, PINN) | жасалмады | Лаб. генераторда қоспа концентрациясы Больцман интенсивтілігімен қолданылады; модель концентрацияны болжамайды | LTE генераторы (Саха теңдеуі, T_e, n_e), регрессия басы, NNLS-пен салыстыру. Керек: NIST иондық (II) сызықтары, деңгей энергиялары мен бөлу функциялары. Бірінші қадам: сызық күшін NIST `Rel` орнына `g_k·A_ki·exp(−E_k/kT)` (деректе `aki`, `gk` бар) арқылы есептеу: нақты LIBS-тағы K сәтсіздігінің өлшенген себебі |
| 2 | Өзін-өзі калибрлеу | ішінара | CFL бойынша автокалибровка (түс арқылы тексеріледі), түс бойынша шамамен калибровка, квадраттық дисперсия, қолмен ROI | Оқытылатын Spatial Transformer (тор бұрышы, қисаю). | 3 | Белгісіздікті бағалау (MC Dropout, evidential) | ішінара | Эвристикалық қорғаныс: үздіксіз спектр қақпасы, сызық сәйкестігімен растау («расталды/расталмады»). Калибровка өлшенді: синтетикада ECE 0.004, нақты LIBS-та нашар (Hg I: >50 % ықтимал, шын жиілік 0, v3 29 % спектрде) | Калибрленген ықтималдық жоқ: модельдің «80%» дегені нақты деректе 80% емес. Алғашқы қадам: ансамбль/MC Dropout, температуралық масштабтау (нақты белгіленген деректе), бейтаныс түрлер (OOD) тесті |
| 4 | Нақты деректермен domain adaptation | ішінара | Нақты фотодан көрілген бұрмалаулар генераторға қосылды (кең/қаныққан сызықтар, блуминг, сызықтық емес дисперсия, CFL класы); `tools/eval_real.py`. Лаб. модель k ≤ 8 қоспаға оқытылды, нақты LIBS-та `eval_libs_species` өлшейді (микро-recall 0.50 → 0.69) | Нақты спектрлермен fine-tune, DANN, CycleGAN: екі сурет жеткіліксіз (камера үшін кемінде 30–50 белгіленген сурет керек). Лаб. үшін SuperLIBS белгіленген, бірақ онымен fine-tune тестті бұзады: бөлек файл/пеллет бөлу керек |
| 5 | Иондану сатысы мен плазма диагностикасы (T_e, n_e) | жасалмады | Базада 27 бейтарап түр, Ca II және Mg II | Fe II, Ti II сияқты иондық сызықтар (Ti II нақты спектрде Ti I-ден жақсы көрінеді), Больцман графигі (T_e), Саха теңдеуі (n_e), Штарк кеңеюі |
| 6 | Молекулалық жолақтар (OH, N₂, CN) | жасалмады | CFL фосфор сызықтары көз класы ретінде | Жолақ шаблондары, denoising autoencoder, атомдық сызықтарды молекулалық фоннан бөлу |

## Нақты SuperLIBS спектрлерінен құрамды бағалау

Құрам моделі Жер атмосферасында 2.4 мДж энергиямен түсірілген, алдын ала өңделген
[Mount Holyoke SuperLIBS 10K](https://zenodo.org/records/10287455) спектріне
SiO₂, TiO₂, Al₂O₃, Fe₂O₃, MgO, CaO, Na₂O және K₂O массалық үлестерін (wt %) болжайды.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install scikit-learn==1.9.1 numpy==2.4.6
.\.venv\Scripts\python.exe -m spectra_ai.train_libs train
.\.venv\Scripts\python.exe -m spectra_ai.train_libs predict unknown.csv --out composition.csv
```

Оқыту үшін әдепкі файл — `data/zenodo.10K_EARTH.2.4mJ.csv`. Болжам CSV-де
бірінші жолда спектр бағандары `wvl` деп белгіленеді, екінші жолда олардың
толқын ұзындықтары (нм) жазылады. 15 498 арнаның мәні мен реті оқыту файлымен бірдей
болуы керек. Болжам үшін құрам бағандары қажет емес. Өлшеу мен алдын ала өңдеу
шарттары оқыту дерегіне сәйкес болуы керек. Сапа осы шартта ғана бағаланды.

Модель `checkpoints/superlibs_earth_2p4mj.joblib` файлына, ал валидация мен
тест метрикалары аттас JSON файлына жазылады. Құрамы бірдей үлгілер бір
бөлікте сақталады. Модель валидация арқылы таңдалады, қателігі бөлек тестте
массалық пайыздық пунктпен есептеледі. Өзгеден алынған сенімсіз joblib файлдарын
жүктемеңіз.

Ridge (α торы 10–100 000) мен MLP салыстырылады, таңдау тек валидация бойынша, тест бір рет қарайды. Тордың шеті таңдалса, `train` ескерту басады (`selected_on_grid_edge` JSON-да): бұрынғы тор 10–1000 болатын, ал валидация MAE α = 1000-ға дейін монотонды төмендеп, оптимум торға тірелген еді.

Валидация MAE (wt %): α = 10 → 1.958 · 100 → 1.692 · 300 → 1.540 · 1000 → 1.412 · 3000 → 1.340 · **10 000 → 1.321** · 30 000 → 1.387 · 100 000 → 1.516 · MLP (128, 64) → 2.135.

Тест (372 спектр, seed 42; оқыту орташасын болжау: орташа MAE 3.989):

| Оксид | SiO₂ | TiO₂ | Al₂O₃ | Fe₂O₃ | MgO | CaO | Na₂O | K₂O | Орташа |
|---|---|---|---|---|---|---|---|---|---|
| MAE, wt % (α = 1000, бұрын) | 3.655 | 0.432 | 1.649 | 1.666 | 1.305 | 0.986 | 0.445 | 0.589 | 1.341 |
| **MAE, wt % (α = 10 000, қазір)** | 3.356 | 0.373 | 1.568 | 1.625 | 1.234 | 0.855 | 0.450 | 0.519 | **1.248** |
| Skill¹ (қазір) | 0.845 | 0.521 | 0.758 | 0.695 | 0.926 | 0.944 | 0.787 | 0.853 | 0.791 |

¹ Skill = 1 − (RMSE / оқыту орташасын болжау RMSE-сі)²: R²-ға ұқсас; 1 — мінсіз, 0 — орташаны болжаудан жақсы емес. MAE оксидтер арасында салыстырылмайды (SiO₂ диапазоны ең үлкен), skill салыстырылады: ең әлсізі TiO₂ мен Fe₂O₃.

Белгісіздік. Бір бөлінудің тест MAE-сі кездейсоқ бөлінуге тәуелді. α = 10 000 үшін 10 басқа бөлінуде (тұқым 0–9) орташа MAE **1.298 ± 0.043** (1.222–1.343; JSON-да `split_seed_spread`), α = 1000 үшін сол бөлінулерде 1.322 ± 0.031 (қосымша өлшеу). Яғни тордың кеңеюінен шынайы пайда ≈ 0.02–0.03 wt %, ал 1.341 → 1.248 секірісінің бір бөлігі осы бөлінудің сәттілігі. Бір санға ± 0.04 wt % белгісіздікпен қараңыз.

## ChemCam және Кépeš өлшемдерінде алдын ала оқыту

[ChemCam](https://huggingface.co/datasets/jfang/ChemCam-LIBS-2512) жеке атыстары
мен агрегаттары және [Képeš](https://pmc.ncbi.nlm.nih.gov/articles/PMC7018695/)
жинағындағы `test.h5` бір автоэнкодерді оқытуға қолданылды. Модель
200–900 нм аралығындағы 1 024 нүктелік торда қолжетімді арналардың шамамен
20%-ын жасырып, сол арналардағы нормаланған интенсивтілікті қалпына келтіреді.
Модельдің шығысы спектрді қалпына келтіруге арналған. Веб-зертхананың
элемент пен температура моделі бөлек жұмыс істейді.

```powershell
py -m pip install numpy pyarrow h5py torch
py -m spectra_ai.pretrain_measured prepare
py -m spectra_ai.pretrain_measured train --epochs 3
```

Дайындалған массивтер әдепкіде `.venv/measured_cache` қалтасына жазылады
(шамамен 2 ГБ). Үш файлдан 989 255 спектр оқылды, 888 716-сы оқытуға,
52 487-сі валидацияға, 48 052-сі тестке алынды. ChemCam нысанасының
аты бірдей жазбалар бір бөлікте сақталды. Кépeš файлында үлгі идентификаторы
болмағандықтан, қатар тұрған 500 спектрлік блоктар бойынша бөлінді.
Бұл файл алдын ала оқытуға кіргендіктен, модельді сол файлмен бастапқы
Кépeš жіктеу бенчмаркінің тәуелсіз қатысушысы ретінде бағалауға болмайды.

Салмақтар `checkpoints/measured_libs.pt` файлына, әр дереккөздің метрикалары
`checkpoints/measured_libs.json` файлына сақталады. RMSE нормаланған
интенсивтілік шкаласында, жасырылған арналарда есептеледі.

### 100 эпохаға дейін жалғастыру

```powershell
py -m spectra_ai.pretrain_measured train --epochs 100 --batch-size 2048 --fast --resume checkpoints/measured_libs.pt --out checkpoints/measured_libs_100.pt
```

`--epochs` аяқталатын эпоха нөмірін білдіреді. Бұл пәрмен үшінші эпоханың
сақталған салмақтарынан бастап, 4–100 эпохаларды орындайды. `--fast` бос
GPU жады жеткілікті болса, өңделген спектрлерді GPU-да сақтайды және
қолдау бар CUDA құрылғыларында bfloat16 аралас дәлдігін қолданады.

Әр аяқталған эпохадан кейін модель мен оптимизатор күйі
`checkpoints/measured_libs_100.last.pt` файлына жазылады. Үзілістен
кейін жоғарыдағы пәрменді `--resume checkpoints/measured_libs_100.last.pt`
мәнімен қайталаңыз. `checkpoints/measured_libs_100.pt` валидацияда ең кіші
орташа RMSE көрсеткен салмақтарды сақтайды. Тест есебі оқыту аяқталған соң
`checkpoints/measured_libs_100.json` файлына жазылады.

100 эпоха аяқталды. Салыстыруда 4-эпоха бұрынғы баптаумен 7,4 секунд,
жылдамдатылған баптаумен шамамен 5,0 секунд өтті. Валидация бойынша үздік
чекпойнт 97-эпохада алынды. Бірдей 48 052 тест спектрі мен жасырылған
арналарда 3-эпоха мен үздік чекпойнттың RMSE көрсеткіштері салыстырылды.
