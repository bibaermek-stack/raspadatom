## Қалай қайталауға болады

```bash
python tools/eval_real.py photo.jpg                       # жолақ автоматты табылады
python tools/eval_real.py photo.jpg --roi '{"cx":650,"cy":500,"theta":1.5707963,"t0":-470,"t1":455,"hv":22}'   # қолмен ROI (бұрыш радианмен)
```

`tools/eval_real.py` суретті веб-интерфейстегідей (ені ≤ 1280 px) жергілікті Node құбырынан өткізеді де JSON шығарады: ROI, CFL және түс бойынша калибровка, модельдің үздік 5 болжамы, физикалық қақпа мен сызық сәйкестігінен кейінгі қорытынды. Сурет ешқайда жіберілмейді.

Веб-интерфейсте дәл осы: «Камера» → «Сурет таңдау» → автоматты ROI сәтсіз болса, суретте жолақ бойымен сызық сүйреңіз → «Автокалибровка».

Қолмен ROI параметрлері (1-сурет): `cx, cy` — ROI орталығы (пиксель), `theta` — жолақ бағыты (рад), `t0, t1` — орталыққа қатысты басы мен соңы, `hv` — жарты қалыңдық. 2-суретте жолақ жоқ, сондықтан кемпірқосақты **көлденең** кесетін қысқа ROI алынды (қызылдан күлгінге).
